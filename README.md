# Fraud Transaction Analysis

## Project Overview

This project analyzes credit card transaction data to identify fraudulent transaction patterns, measure fraud activity, and present key findings through an interactive Power BI dashboard.

The analysis follows an end-to-end data analytics workflow:

*Excel → SQL → Power BI*

## Business Objective

The objective of this project is to:

- Analyze overall transaction activity
- Identify fraudulent transactions
- Calculate the fraud rate
- Analyze transaction amounts
- Compare fraudulent and legitimate transactions
- Identify patterns that can support fraud monitoring and decision-making
- Present the findings through an interactive dashboard

## Tools Used

### Excel
- Initial data inspection
- Data cleaning and preparation
- Data validation
- Preparation of the dataset for SQL analysis

### SQL Server
- Data querying
- Data validation
- Transaction analysis
- Fraud transaction analysis
- Calculation and verification of key metrics

### Power BI
- Data visualization
- KPI development
- Interactive dashboard development
- Charts and slicers
- Key findings and analytical storytelling

## Key KPIs

The Power BI dashboard includes:

- *Total Transactions:* 284,807
- *Fraud Transactions:* 473
- *Fraud Rate:* 0.17%
- *Average Fraud Amount:* 123.90

## Key KPIs

The Power BI dashboard includes:

- *Total Transactions:* 284,807
- *Fraud Transactions:* 473
- *Fraud Rate:* 0.17%
- *Average Fraud Amount:* 123.90

## Dashboard Analysis

The dashboard provides visual analysis of:

- Total transactions by class
- Fraud transactions by class
- Transaction amount distribution
- Average fraud amount by class
- Key findings from the analysis

A slicer is also included to allow users to interactively filter the dashboard.

## Project Workflow

### 1. Excel
The dataset was initially reviewed and prepared in Excel before being moved into SQL Server.

### 2. SQL
SQL Server was used to query and analyze the cleaned dataset and verify key transaction and fraud metrics.

### 3. Power BI
The SQL-processed data was imported into Power BI, where KPIs, visualizations, interactive filtering, and the final dashboard were developed.

## Key Findings

- The dataset contains *284,807 transactions*.
- *473 transactions* were identified as fraudulent.
- The overall fraud rate is *0.17%*.
- Fraudulent transactions represent a very small proportion of the total transaction volume.
- The dashboard provides a visual breakdown of transaction activity and fraud-related patterns.
